# CRM Web Application

📅 **Date**: Janvier 2025  
🧑‍💻 **Développeur**: Anass El Hadi  
🌐 **Technologies**: Java, JSP/Servlets, MySQL, HTML, CSS, JavaScript, Bootstrap, Facebook API, SMTP

---

## 📌 Description

Cette application CRM (Customer Relationship Management) est une plateforme web conçue pour centraliser la gestion des interactions client, améliorer le suivi des opportunités commerciales et optimiser la communication entre les utilisateurs et les administrateurs.

---

## 🎯 Fonctionnalités principales

### 👥 Côté Client
- Soumission de rapports
- Participation à des sondages via e-mail (SMTP)
- Consultation de l’historique des interactions et des rapports précédents

### 🛠️ Côté Administrateur
- Visualisation de statistiques publicitaires via les APIs **Facebook** et **Instagram**
- Gestion et publication de contenus via l’API Facebook
- Envoi automatisé de sondages et d'opportunités aux clients (SMTP)
- Gestion complète des contacts, des opportunités et des campagnes marketing

---

## 🧰 Stack Technique

- **Back-end** : Java, Servlets, JSP
- **Front-end** : HTML, CSS, JavaScript, Bootstrap
- **Base de données** : MySQL
- **APIs** : Facebook Graph API, SMTP (JavaMail)

---

## 📈 Impact

> L'application permet une gestion centralisée et efficace de la relation client, adaptée à un environnement multi-acteurs. Elle améliore la productivité des administrateurs tout en offrant une interface fluide pour les utilisateurs.
